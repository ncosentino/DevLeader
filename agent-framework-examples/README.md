Sample applications demonstrating the Microsoft Agent Framework (MAF) in C#, built to accompany the Dev Leader blog series. Each subfolder is a standalone .NET 10 application showcasing different agent patterns and architectures.

## Projects

| Project | Description |
|---------|-------------|
| [content-pipeline](./content-pipeline/) | Sequential and parallel agent workflow orchestration for content generation |
| [agent-evaluator](./agent-evaluator/) | AI agent evaluation harness using the LLM-as-judge pattern |
| [mcp-tool-agent](./mcp-tool-agent/) | Agent with MCP tool integration |
| [multi-agent-research](./multi-agent-research/) | Multi-agent research collaboration system |
