This interactive console application demonstrates and compares different concurrency patterns in C#. It presents a menu-driven interface that lets you run different threading examples side by side, making the behavioral differences between each approach immediately visible. Each example implements a common `IExample` interface with a name, description, and execution method.

The included examples cover: non-background threads (which keep the application alive even after the main thread exits), background threads (which are terminated when the main thread exits), the `BackgroundWorker` component (which provides built-in progress reporting and completion events), and simultaneous execution patterns showing multiple concurrent operations. This is a practical reference for understanding when and why to choose different threading approaches in .NET.

## Getting Started

### Prerequisites
- .NET 7.0 SDK or later

### Running the Project
```bash
cd ConcurrentContrasts
dotnet run
```

Follow the interactive menu to select and run different concurrency examples.
