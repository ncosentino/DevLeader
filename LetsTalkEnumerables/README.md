# LetsTalkEnumerables - IEnumerable Lazy Evaluation and Deferred Execution Patterns in C#

This .NET 8.0 solution explores IEnumerable patterns through two focused projects. The `ExploringLaziness` project demonstrates the difference between lazy evaluation using `yield return` and eager evaluation with immediate materialization, using `Stopwatch` measurements and `Any()` calls to show when work actually occurs. It includes BenchmarkDotNet integration for performance comparisons between the two approaches.

The `HoldingResources` project addresses a critical pitfall: managing resource lifetimes with deferred execution. It demonstrates how returning an IEnumerable reference can cause premature resource disposal, and shows the correct pattern using `yield return` within a `using` block to keep resources alive during enumeration. The project also explores async enumeration complexities with `Task.Run` for background thread execution, illustrating subtle timing and thread-safety issues when passing IEnumerable across architectural layers.

## Getting Started

### Prerequisites
- .NET 8.0 SDK or later

### Running the Project
```bash
cd LetsTalkEnumerables/ExploringLaziness
dotnet run
```
