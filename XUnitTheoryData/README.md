# XUnitTheoryData - xUnit Theory and Parameterized Test Patterns in C#

[![YouTube](https://img.shields.io/badge/YouTube-Dev%20Leader-red?logo=youtube)](https://www.youtube.com/@devleader)

[![LinkedIn](https://img.shields.io/badge/LinkedIn-Nick%20Cosentino-blue?logo=linkedin)](https://www.linkedin.com/in/nickcosentino/)

xUnit test project demonstrating parameterized test data patterns using Theory attributes and MemberData. Features an Adder class with a simple Add method and AdderTests that use a strongly-typed AdderTestScenario record to encapsulate test parameters.

Tests cover multiple scenarios including zero addition, positive numbers, and negative numbers. Includes commented-out examples showing alternative data patterns: IEnumerable<object[]>, TheoryData<T> generics, and ClassData with derived TheoryData classes. .NET 8, xUnit 2.9.0.

## Getting Started

### Prerequisites
- .NET 8.0 SDK

### Running the Project
```bash
cd XUnitTheoryData\XUnitTheoryData
dotnet test
```
