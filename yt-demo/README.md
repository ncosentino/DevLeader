## 🗂️ Projects

### PokedexBlazor

A **Blazor WebAssembly** Pokédex app that consumes the public [PokéAPI](https://pokeapi.co/) — built entirely through Claude Flow agent swarms without manually writing a single line of code.

**Features:**
- Browse and search all Pokémon with live filtering
- Pokémon detail modal with stats, types, and sprites
- Persistent favorites saved to browser local storage
- Responsive UI using Bootstrap 5

**Tech Stack:**
- Blazor WebAssembly (.NET 9)
- PokéAPI (free, no auth required)
- Bootstrap 5

**Run it:**
```bash
cd PokedexBlazor
dotnet run
```
Then open `http://localhost:5047` in your browser.

## 🔑 Key Concepts

- **Claude Flow** — an orchestration framework that runs multiple Claude AI agents as a coordinated swarm to design, implement, and review code
- **Vibe Coding** — describing an application in natural language and letting AI agents generate the full implementation
- **Blazor WebAssembly** — running C# directly in the browser via WebAssembly, with no server-side rendering
