# WpfPlayground - WPF Plugin Architecture with Dependency Injection in C#

Advanced WPF sample application demonstrating plugin architecture, dependency injection, and programmatic UI composition. The SampleApplication uses Microsoft.Extensions.DependencyInjection and Scrutor for assembly scanning to dynamically load and register plugin assemblies at runtime.

Features include an async splash screen with progress reporting, a multi-step wizard with forward/back navigation and step history, and a custom "Stitcher" factory pattern for dynamic UI element composition. The WpfPlayground.Plugin1 project demonstrates a loadable plugin with custom value converters, and the WpfPlayground.Sdk provides the IMainWindow interface contract for loose coupling between core and plugins.

.NET 8.0-windows.

## Getting Started

### Prerequisites
- .NET 8.0 SDK with Windows Desktop workload
- Windows OS

### Running the Project
Build the entire solution with:
```bash
dotnet build
```

Then run:
```bash
dotnet run --project WpfPlayground.SampleApplication
```
