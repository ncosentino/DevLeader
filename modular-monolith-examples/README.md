Sample applications demonstrating modular monolith architecture patterns in C# and .NET, built to accompany the Dev Leader blog series. Each subfolder explores a different aspect of modular monolith design, from structuring modules to migrating toward microservices.

## Projects

| Project | Description |
|---------|-------------|
| [modular-monolith-demo](./modular-monolith-demo/) | Core modular monolith architecture demonstration |
| [strangler-fig-migration](./strangler-fig-migration/) | Strangler Fig pattern for incremental monolith-to-microservices migration using YARP |
| [distributed-monolith-antipattern](./distributed-monolith-antipattern/) | Demonstrates the distributed monolith antipattern and how to avoid it |
