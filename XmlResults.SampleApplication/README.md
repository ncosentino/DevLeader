ASP.NET Core web application demonstrating XML serialization and custom result types in minimal APIs. Implements a custom XmlResult<T> class that implements IResult to serialize objects to XML using XmlSerializer.

Features three routes: "/" returns raw XML strings, "/serialize" uses the custom XML result to serialize a data object, and "/controller" demonstrates controller-based XML endpoints. Includes XmlResultExtensions for fluent API usage. .NET 9, no external dependencies beyond ASP.NET Core built-ins.

## Getting Started

### Prerequisites
- .NET 9.0 SDK

### Running the Project
```bash
cd XmlResults.SampleApplication\XmlResults.SampleApplication
dotnet run
```

Then browse to the displayed URL.
