C# project demonstrating the UnsafeAccessor attribute introduced in .NET 8, which allows bypassing visibility restrictions to access private members at compile time without reflection overhead. The console app showcases accessing private constructors, fields, properties, methods, and their static variants using extern static methods decorated with [UnsafeAccessor].

The benchmark project compares UnsafeAccessor performance against traditional reflection-based access using BenchmarkDotNet 0.14.0. This highlights the significant performance advantage of UnsafeAccessor, which avoids the runtime cost of reflection by resolving member access at JIT compile time.

## Getting Started

### Prerequisites
- .NET 8.0 SDK

### Running the Project
Run the console demo:
```bash
cd UnsafeAccessors.ConsoleApp
dotnet run
```

Run the benchmarks:
```bash
cd UnsafeAccessors.Benchmarks
dotnet run -c Release
```
