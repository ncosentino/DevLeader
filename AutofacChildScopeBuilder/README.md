# AutofacChildScopeBuilder - Autofac Child Lifetime Scopes and Dynamic Plugin Loading

This project demonstrates how to use Autofac child lifetime scopes to dynamically register and resolve plugin types at runtime. The pattern involves loading assemblies, filtering for types that implement an `IPlugin` interface, and registering them within a child scope rather than the root container. This approach is useful for plugin architectures where you want to isolate dynamically loaded components from the rest of the application's dependency graph.

Child lifetime scopes in Autofac allow you to supplement or override registrations without polluting the root container. When the child scope is disposed, all services resolved from it are cleaned up as well. This example shows the full workflow: scanning assemblies for plugin types, creating a child scope with those registrations, and resolving plugin instances from the scoped container.

## Getting Started

### Prerequisites
- .NET 7.0 SDK or later
- NuGet package: `Autofac` v7.1.0

### Running the Project
```bash
cd AutofacChildScopeBuilder
dotnet run
```
