Sample applications demonstrating the GitHub Copilot SDK for .NET, built to accompany the Dev Leader blog series. Each subfolder is a standalone .NET 9 app using `appsettings.json` for configuration.

## Apps

| App | Description | Blog Article |
|-----|-------------|--------------|
| [ai-cli-tool](./ai-cli-tool/) | Interactive AI coding assistant as a .NET CLI tool | [Build an AI CLI Developer Tool with Copilot SDK](https://www.devleader.ca/2026/03/23/github-copilot-sdk-ai-cli-tool-csharp) |
| [ai-assistant-api](./ai-assistant-api/) | ASP.NET Core minimal API exposing Copilot conversations | [Build an ASP.NET Core AI Assistant API](https://www.devleader.ca/2026/03/24/github-copilot-sdk-aspnet-core-ai-api-csharp) |
| [coding-agent](./coding-agent/) | Iterative generate/fix code loop using Copilot SDK | [Build an Interactive Coding Agent](https://www.devleader.ca/2026/03/25/github-copilot-sdk-coding-agent-csharp) |
| [repo-analysis-bot](./repo-analysis-bot/) | GitHub repo reader and insight generator | [Build a Repository Analysis Bot](https://www.devleader.ca/2026/03/26/github-copilot-sdk-repo-analysis-bot-csharp) |
| [multi-agent-system](./multi-agent-system/) | Multiple Copilot sessions collaborating on shared tasks | [Build a Multi-Agent System with GitHub Copilot SDK](https://www.devleader.ca/2026/03/31/github-copilot-sdk-multi-agent-system-csharp) |
