# LazyExample - Lazy Initialization in C# with Lazy&lt;T&gt; for Deferred Expensive Operations

This .NET 7.0 console application demonstrates lazy initialization using `Lazy<Task<int>>` to defer expensive asynchronous operations until they are actually needed. The program wraps an expensive async operation in a `Lazy<T>` object, showing that creation is instant, the actual computation (a 2-second delay simulating an expensive operation) only executes on first access, and all subsequent accesses return the cached result immediately with no additional overhead.

This pattern is particularly useful for scenarios involving database queries, API calls, or complex computations that should only run once and only when their results are actually required. The example clearly demonstrates the performance benefits of lazy initialization by timing each access to the lazy value.

## Getting Started

### Prerequisites
- .NET 7.0 SDK or later

### Running the Project
```bash
cd LazyExample
dotnet run
```
