This project provides a foundational introduction to iterators in C# and .NET. It covers what iterators are, how the `yield return` and `yield break` keywords work, and how the compiler transforms iterator methods into state machines under the hood.

Iterators are a fundamental building block of lazy evaluation in C#. Understanding how they function — including when execution is deferred and how state is preserved between `MoveNext()` calls — is essential for writing efficient and predictable LINQ pipelines and custom enumerable sequences.
