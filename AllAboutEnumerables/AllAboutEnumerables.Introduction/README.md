This project is a beginner-friendly introduction to `IEnumerable<T>` in C# and .NET. It demonstrates the fundamentals of working with enumerable sequences, how lazy evaluation works, and how `IEnumerable<T>` fits into the broader .NET collection hierarchy.

`IEnumerable<T>` is one of the most important interfaces in .NET — it underpins LINQ, `foreach` loops, and most collection-based APIs. Understanding it from the ground up is essential for writing clean, efficient C# code. This example walks through the core concepts with practical, easy-to-follow code.
