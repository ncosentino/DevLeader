This project demonstrates common pitfalls when working with iterators and collections in C# and .NET. Many developers use `IEnumerable<T>` and iterator patterns without fully understanding their deferred execution semantics, multiple-enumeration hazards, and subtle behavior differences — this example makes those dangers explicit with practical code.

From unintended side effects caused by multiple enumeration, to LINQ chains that silently re-query data sources, to iterator state machine edge cases — this project is a practical reference for avoiding the bugs that catch even experienced .NET developers off guard.
