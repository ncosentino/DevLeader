# IoC Singleton Example - Manual Inversion of Control Container with Singleton Pattern in C#

This .NET Framework 2.0 project demonstrates how to implement a lightweight Inversion of Control (IoC) container using the singleton pattern without relying on external IoC frameworks. The solution contains a console application and an `ApplicationLayer` class library where the core IoC logic resides. The `Application` class acts as both a singleton manager with thread-safe double-checked locking and a service locator that uses an event-based system to decouple type selection from instantiation.

The project uses .NET Reflection to instantiate concrete types at runtime, expecting implementations to have private parameterless constructors. Consumers subscribe to the `QueryType` event before accessing `Application.Instance`, and the event handler specifies which concrete type to use. This demonstrates the fundamental concepts behind dependency injection and IoC containers that modern frameworks like Microsoft.Extensions.DependencyInjection provide out of the box.

- Visual Studio

### Running the Project
Open the solution in Visual Studio and run the console application.
