This is a simple interactive console application that demonstrates Base64 encoding and decoding in C#. The program runs in a loop, prompting you to enter a string to encode to Base64 and then a Base64 string to decode back to UTF-8 text. It uses `System.Convert.ToBase64String` and `System.Convert.FromBase64String` along with `System.Text.Encoding.UTF8` for the byte conversions.

Base64 encoding is commonly used for embedding binary data in text-based formats such as JSON, XML, or email. This example provides a quick hands-on way to experiment with encoding and decoding operations directly from the command line.

## Getting Started

### Prerequisites
- .NET 8.0 SDK or later

### Running the Project
```bash
cd Base64Encocoding
dotnet run
```
