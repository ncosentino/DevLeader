This Android educational project demonstrates how to implement a tabbed user interface using Fragments and the Android Support Library. It uses `FragmentActivity` for backward compatibility with a minimum SDK of 8 and a target SDK of 18. This is a Java/Android project, NOT a C#/.NET project.

The project features a `TabsFragment` that handles dynamic fragment replacement on tab switch, an abstract `TabDefinition` base class that uses the template method pattern to define tab behavior, and a `SimpleTabDefinition` for text-based tabs. This architecture makes it easy to add new tab types by extending the base class.

Built with Eclipse and `android-support-v4.jar`, this project serves as a reference for the classic Android fragment-based tab pattern. While modern Android development uses Jetpack Compose or ViewPager2, the fragment management concepts demonstrated here remain relevant.

## Getting Started

### Prerequisites
- Android SDK (API 18)
- Eclipse IDE or Android Studio
- Java JDK

### Running the Project
Import the project into Eclipse or Android Studio, build and run on an emulator or device.
